# Supabase Database Schema

This folder contains the SQL script to set up the necessary tables for this project in your Supabase database.

## Instructions

1.  **Copy the SQL script:** Open the `schema.sql` file and copy its entire content.
2.  **Navigate to the Supabase SQL Editor:**
    *   Go to your Supabase project.
    *   Click on the "SQL Editor" tab in the left sidebar.
3.  **Run the script:**
    *   Paste the copied SQL into the editor.
    *   Click the "Run" button.

This will create the `courses` table with the correct columns and types, allowing the application to save course data correctly.
